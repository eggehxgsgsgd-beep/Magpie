# Magpie — 图像分类工具 PRD v2（重写版）

> 本版本相对 v1 的核心变化：
> 1. **去掉 YAML 配置文件**，所有配置改为 UI 内完成，标注用户零接触文本配置。
> 2. **明确跨平台交付**：Windows / macOS / Linux 三端打包，通过 GitHub Actions 自动化构建发布。
> 3. **清零 v1 PRD 第 7 节列出的全部已知技术债**，作为重写的硬性约束。

---

## 1. 产品定位

一个**单机桌面 GUI 工具**，让数据标注/算法工程师通过键盘快捷键，把本地图片快速分桶到不同类别文件夹下，用于数据集清洗与归类。

**核心价值**：键盘驱动的高速分类，单张图片处理时间 < 1 秒。

**目标用户**：
- **主用户（标注员）**：只用键盘做分类，不希望接触任何配置文件、命令行。
- **次要用户（工程师）**：定义类别和快捷键映射，把配置分享给团队成员。

---

## 2. 设计原则

| 原则 | 含义 |
| --- | --- |
| **零配置文件** | 用户不应需要打开任何 yaml/json/ini 编辑。所有设置在 UI 内完成。 |
| **开箱即用** | 双击启动即可工作；首次启动有清晰引导。 |
| **配置可分享** | 团队成员之间可通过 UI 导出/导入"配置预设" |
| **跨平台一致** | Windows / macOS / Linux 行为与界面一致，无平台特有分支逻辑 |
| **可下载即用** | 通过 GitHub Releases 发布预打包二进制，用户无需安装 Python |

---

## 3. 核心使用流程

### 3.1 首次启动

1. 用户下载并双击应用，主窗口打开。
2. 主区域显示空状态引导卡片：
   > "欢迎使用 Magpie。请先在 **设置 → 类别** 中定义你的分类按键，然后点击 **打开图片文件夹** 选择待分类的图片目录。"
3. 配套两个明显的入口按钮：`打开设置`、`打开图片文件夹`。
4. 用户进入设置，定义类别（按键 → 类别名），设置输出目录，保存。
5. 回到主窗口，点击"打开图片文件夹"，开始分类。

### 3.2 日常使用

1. 双击应用 → 自动恢复上次的图片文件夹与浏览位置。
2. `← / →` 浏览，按定义好的快捷键将图片归类。
3. 关闭窗口 → 状态自动持久化。

## 4. 功能需求

### 4.1 设置与持久化（替代原 YAML）

**存储位置**：使用 `QStandardPaths.AppDataLocation`，由 Qt 自动给出各平台规范路径：

| 平台 | 路径 |
| --- | --- |
| Windows | `%APPDATA%\Magpie\` |
| macOS | `~/Library/Application Support/Magpie/` |
| Linux | `~/.local/share/Magpie/` |

**存储为两个文件，职责分离**：

| 文件 | 内容 | 用户感知 |
| --- | --- | --- |
| `preferences.json` | 用户偏好（类别、输出目录、显示选项等） | 可在 UI 内导出/导入 |
| `state.json` | 运行时状态（上次打开的文件夹、上次索引、窗口位置等） | 完全自动管理，用户无感 |

**注意**：内部用 JSON 但**用户绝不需要打开它**。提供"导出预设 / 导入预设"功能时，使用 `.magpie-preset.json` 后缀让用户能保存为可分享的文件。

### 4.2 设置 UI

**入口**：菜单栏 `编辑 → 首选项`，或快捷键 `Ctrl+,`（macOS 上为 `Cmd+,`）。

**对话框结构（左侧 Tab 切换）**：

#### Tab 1：类别（最核心）

一个可编辑的表格，列：

| 快捷键 | 类别文件夹名 | 显示名称（可选） | 颜色（用于 BBox） | 操作 |
| --- | --- | --- | --- | --- |
| 1 | cat | 猫 | 绿色色块 | 🗑 |
| 2 | dog | 狗 | 蓝色色块 | 🗑 |
| ... | ... | ... | ... | ... |

控件：
- **"添加类别"按钮**：新增一行。
- **快捷键输入**：点击单元格触发"按下单键"捕获模式 —— **仅接受单个可见字符**（a–z、A–Z、0–9、以及 `- = [ ] ; ' , . /` 等常规符号），**拒绝组合键、方向键、功能键 F1–F12、Tab、回车、空格**。系统实时检测冲突：与系统快捷键（含视图快捷键 `F / 0 / B`）或与已有类别快捷键重复时，红框 + 错误提示，阻止保存。
- **类别文件夹名**：输入时实时校验（不含 `/ \ : * ? " < > |` 等非法字符）。
- **显示名称**：可选，UI 中显示用，默认与文件夹名一致，支持中文。
- **颜色**：双击打开颜色选择器，默认从 12 色调色板按序自动分配。
- **行重排**：拖动调整顺序（影响右侧面板的展示顺序）。
- **删除行**：垃圾桶图标，删除前确认。

#### Tab 2：文件夹

| 字段 | 说明 |
| --- | --- |
| 默认图片来源目录 | "打开图片文件夹"对话框的起始路径。预设此处后，启动 + 点开就直接落到常用目录，不用每次重新选。 |
| 默认输出目录 | 分类结果的根目录；每个类别会在此创建同名子文件夹。带"选择…"按钮。 |
| 默认标签目录 | YOLO label 文件目录（可选）。 |
| classes.txt 路径 | 可选；若指定则覆盖 BBox 的类别名显示。 |

#### Tab 3：显示

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| 自动播放间隔 | 100 ms | 滑块 50–2000ms |
| 默认显示 BBox | 开 | 切换开关 |
| 显示已分类标记 | 开 | 在文件列表/缩略图中标记已经分到某类的图 |
| 主题 | 跟随系统 | 浅色 / 深色 / 跟随系统 |

#### Tab 4：行为

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| 默认操作 | 复制 | 复制 / 移动 二选一 |
| 撤销后弹提示框 | 关 | （v1 默认开，对高频用户是干扰，此处改为默认关） |
| 到达末尾时 | 停留 | 停留 / 提示 / 循环 三选一（v1 强制弹关闭对话框，改掉） |
| 支持的文件类型 | jpg, jpeg, png, bmp, webp, tiff | 多选复选框（v1 仅 jpg/jpeg/png） |

#### Tab 5：导入/导出

- **导出预设**：把当前类别配置与显示偏好导出为 `.iclspreset.json` 文件，方便分享给同事。
- **导入预设**：从文件加载，覆盖当前类别配置（导入前弹确认框）。
- **重置为默认**：清空所有偏好，回到初始状态。

**保存逻辑**：点击"应用"或"确定"时，校验全部通过才落盘并立即生效。校验失败的字段红框 + 顶部错误提示，禁止保存。

### 4.3 文件夹与图像加载

- 入口：菜单"文件 → 打开图片文件夹"，或主窗口工具栏按钮，或**拖拽文件夹到窗口**。
- 支持的扩展名由设置决定（默认 jpg/jpeg/png/bmp/webp/tiff）。
- 文件读取使用 **Pillow**（替代 v1 的 cv2 + numpy 字节缓冲方案），原生支持非 ASCII 路径，依赖更轻。
- 排序策略：下拉菜单可选，默认"文件名（自然排序）"。可选：文件名升序 / 文件名降序 / 修改时间升降 / 大小升降。
- 打开新文件夹时：清空撤销历史、按当前类别配置预创建输出子文件夹、重置浏览索引。

### 4.4 图像浏览与显示

| 行为 | 触发 |
| --- | --- |
| 上一张 / 下一张 | `← / →` |
| 自动播放/暂停 | `Space`，间隔来自设置 |
| 跳转到指定序号 | 工具栏"跳转"按钮或 `Ctrl+G`，弹出整数输入框 |
| 复制当前文件名 | 工具栏按钮或 `Ctrl+C`（仅在图片区域聚焦时） |
| 到达末尾 | 按设置中的行为（停留/提示/循环） |

底部状态栏：`当前索引 / 总数` · `当前文件名` · `当前文件夹路径` · `已分类标记`。

**自动播放与分类的交互**：核心使用场景是"自动播放浏览 → 看到要保留的图按分类键拦截"。要求：
- 自动播放运行时，**分类键立即响应**，不被 timer 节奏阻塞。
- 分类操作完成后立即 `next_image()` 并重置 timer 的下一个 tick，保持节奏连续。
- `Space` 任何时候再按一次都能立即暂停。
- 自动播放期间，撤销 / 重做也立即生效（撤销会自动暂停播放，给用户检查时间）。

### 4.5 图像视图（重写关键点）

**用 `QGraphicsView` + `QGraphicsScene` + `QGraphicsPixmapItem`** 替代 v1 的"裸 QLabel + 手动 move()"方案。

| 行为 | 触发 |
| --- | --- |
| 缩放 | 鼠标滚轮（以光标位置为锚点） |
| 平移 | 鼠标左键拖动（`ScrollHandDrag` 模式） |
| 适应窗口 | 右键单击 或 工具栏"适应窗口"按钮 或 `F` 键 |
| 1:1 实际大小 | 工具栏"1:1"按钮 或 `0` 键 |

不再有 Windows/Linux 双套 reset 逻辑。`fitInView(item, KeepAspectRatio)` 一行搞定。

### 4.6 分类操作

- 按下类别快捷键 → 当前图像复制或移动到 `输出目录/<类别文件夹名>/<原文件名>`。
- 复制 / 移动模式由设置中的"默认操作"决定；可通过工具栏切换按钮临时改变（带视觉指示，例如按钮颜色不同）。
- 移动模式下：从内存列表移除该图，索引调整；列表空了显示空状态。
- 复制模式下：在状态栏短暂浮现"已分类到 cat"提示（toast，2 秒消失），不打断节奏。
- 操作完成后自动 `next_image()`。
- **目标文件已存在的冲突策略**：弹出冲突对话框，让用户选择 `跳过 / 覆盖 / 重命名（自动加 _1 后缀） / 取消`。对话框包含"**对本次会话记住此选择**"复选框 —— 勾选后，本次启动期间相同冲突不再弹窗，避免批量分类时的点击地狱。会话结束（关闭程序）后该记忆清除，下次启动重新弹出。
- "取消"选项不计入历史栈，操作视为未发生。

#### 已分类标记持久化

为支持"关闭后重开仍能看出哪些图分过、分到哪了"，应用为**每个源文件夹**维护一份分类记录：

- **存储位置**：`<AppData>/Magpie/classifications/<sha1(源文件夹绝对路径)>.json`。这样源文件夹本身保持干净（不写 sidecar 文件），多个源目录互不污染。
- **数据结构**：
  ```json
  {
    "source_folder": "/abs/path/to/source",
    "last_updated": "2025-XX-XXTxx:xx:xxZ",
    "entries": {
      "image_001.jpg": ["cat"],
      "image_002.jpg": ["dog", "other"]
    }
  }
  ```
  `entries` 的值是**类别列表**，因为复制模式下同一张图可能被多次分类到不同类别。
- **更新时机**：每次分类成功后立即追加；撤销时移除对应记录；重做时再加回。
- **UI 呈现**：
  - 主图区左上角小角标显示该图当前的分类标记（如 `[已分类: cat]`）。
  - 右侧类别列表每行显示该类别的累计数。
  - 状态栏整体显示 `已分类 N / 总数 M`。
- **同源文件夹被复用**：用户再次打开同一个源文件夹时，自动加载分类记录，已分类的图带视觉标记（不影响浏览顺序）。
- **手动重置**：菜单"操作 → 清除本文件夹的分类记录"可手动清空记录文件（不删除已分到输出目录的图）。

### 4.7 撤销 / 重做

- 撤销栈：最近 100 条操作，结构同 v1（源路径、目标路径、类别、操作时索引、操作类型）。
- 重做栈：v1 没有，本版**新增**。撤销后产生重做项，做任何新分类时清空重做栈（标准模式）。
- 快捷键：`Ctrl+Z` 撤销 / `Ctrl+Y` 或 `Ctrl+Shift+Z` 重做。
- 状态栏左侧显示撤销栈深度（如 `撤销可用: 7`）。

### 4.8 BBox 可视化（YOLO 格式）

- 数据来源：设置中的"默认标签目录"，或菜单"文件 → 打开标签目录"临时切换。
- 标签文件查找：基于图片文件 `stem` 拼接 `.txt`（修复 v1 仅识别 .jpg 的 bug）。
- 标签格式：YOLO `class cx cy w h [confidence]`，多余字段忽略。
- 渲染：**Qt 原生**（`QPainter.drawRect` + `drawText`），支持中文类名（修复 v1 OpenCV putText 中文乱码）。
- 颜色：使用设置中为每个类别配置的颜色（在 4.2 Tab 1）。若标签 class id 超出已配置类别数，使用灰色 + 显示原始数字。
- 类别名优先级：`classes.txt`（设置中指定路径） > 类别配置中的"显示名称" > 类别索引数字。
- 视图菜单：`显示 BBox` 复选项（快捷键 `B`）。

### 4.9 快捷键总览

| 类别 | 快捷键 | 行为 |
| --- | --- | --- |
| 导航 | `← / →` | 上/下一张 |
| 导航 | `Space` | 自动播放/暂停 |
| 导航 | `Ctrl+G` | 跳转到序号 |
| 编辑 | `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| 编辑 | `Ctrl+C` | 复制图片名到剪贴板 |
| 视图 | `F` | 适应窗口 |
| 视图 | `0` | 1:1 实际大小 |
| 视图 | `B` | 切换 BBox 显示 |
| 视图 | `+ / -` | 放大 / 缩小（键盘备用） |
| 文件 | `Ctrl+O` | 打开图片文件夹 |
| 设置 | `Ctrl+,` | 打开首选项 |
| 应用 | `Ctrl+Q` | 退出（macOS 为 `Cmd+Q`） |
| 用户自定义 | 用户在设置中分配 | 分类到对应类别 |

**约束**：用户自定义类别快捷键时，UI 阻止与上表中所有系统快捷键冲突。

### 4.10 菜单与工具栏

## 5. UI 设计规范

- 主窗口默认尺寸 1280×800，最小尺寸 960×600。
- 三段式布局：顶部工具栏（48px）· 中间主区域 · 底部状态栏（24px）。
- 主区域左右分栏，可拖动分隔条；右侧最小宽度 240px，最大 400px。
- 右侧面板：类别速查列表（来自当前配置，按设置中的排序），每行 `[色块] 快捷键  显示名称  当前已分计数`。
- 主题：浅色 / 深色 / 跟随系统，由设置控制。
- 不内嵌任何字符串硬编码颜色（v1 各处散落了十几处 `#xxx`），统一通过 `QPalette` + 主题样式表管理。

## 6. 架构与模块拆分

```

│   ├── icons/

```

**依赖（精简）**：
- `PyQt6`（必需）
- `Pillow`（图像加载，替代 opencv-python + numpy）
- 移除：`PyYAML`、`bidict`、`matplotlib`、`opencv-python`

打包体积预计从 v1 的 ~250MB 降到 ~80MB。

## 7. 非功能需求

| 项 | 要求 |
| --- | --- |
| 启动时间 | 冷启动 < 2 秒（打包后） |
| 单张图加载到显示 | < 100 ms（与自动播放间隔匹配） |
| 跨平台 | Windows 10+ / macOS 12+ / Ubuntu 20.04+ 表现一致 |
| 非 ASCII 路径 | 全平台支持（含中文、emoji 路径） |
| 内存占用 | 浏览 1 万张图片的目录时 < 500 MB |
| 错误容错 | 配置文件读写失败、图像损坏、撤销失败均不崩溃，有明确提示 |
| 日志 | 写入用户数据目录下 `logs/app.log`，最近 7 天滚动保留 |

### 8.2 打包工具

**主选 PyInstaller**（PyQt6 生态最成熟）。每平台一个 `spec` 文件，集中在 `packaging/` 目录：

```
packaging/
├── windows.spec
```

### 8.3 GitHub Actions 工作流

三个工作流：

#### `ci.yml`（每个 PR 与 push 触发）
- 矩阵：`{ubuntu-latest, windows-latest, macos-latest}` × Python 3.11
- 步骤：
  1. checkout
  2. 安装依赖（pip install -e ".[dev]"）
  3. 运行 ruff lint
  4. 运行 pytest（含 Qt 测试，使用 `pytest-qt`）
  5. 上传覆盖率报告

#### `build.yml`（push 到 main 触发，仅冒烟）
- 矩阵：全平台
- 步骤：1) 打包 2) 运行打包产物的 `--version` 校验启动可执行 3) 上传 artifact（保留 14 天）

#### `release.yml`（push tag `v*` 触发）
- 矩阵：
  ```yaml
  strategy:
    matrix:
      include:
        - os: windows-latest
          target: windows-x64
        - os: macos-13         # Intel
          target: macos-x64
        - os: macos-14         # Apple Silicon
          target: macos-arm64
        - os: ubuntu-22.04
          target: linux-x86_64
  ```
- 每个矩阵任务：
  1. checkout（含 tags）
  2. setup-python 3.11
  3. 安装依赖
  4. 运行 `python packaging/build.py --target ${{ matrix.target }}` —— 内部分发到对应 spec
  5. 平台后处理：
     - Windows：直接产出 exe
     - macOS：`create-dmg` 打包 `.app` 为 `.dmg`
     - Linux：`appimagetool` 产出 `.AppImage`
  6. 上传 artifact
- 汇总任务：`needs: [build matrix]`，下载所有 artifact，附加到由 tag 触发创建的 GitHub Release。
- Release Notes：从 `CHANGELOG.md` 中对应版本段落自动提取。

### 8.5 版本号管理

## 9. 原版技术债清零对照表

| # | v1 问题 | v2 解决方案 |
| --- | --- | --- |
| 1 | 标签文件名硬编码 `.jpg → .txt` | 改用 `Path(name).with_suffix('.txt')` |
| 2 | `matplotlib.cm.get_cmap` 已弃用 | 完全移除 matplotlib 依赖，内置 12 色调色板 |
| 3 | `cv2.putText` 不支持中文 | 改用 `QPainter.drawText`，原生 Unicode |
| 4 | 平移直接 move() QLabel，行为诡异 | `QGraphicsView` + `ScrollHandDrag` |
| 5 | Windows / Linux 双套 reset 逻辑 + 冗余调用 | `fitInView()` 一行实现，平台无关 |
| 6 | `next_image` 取模回绕与"末尾弹关闭"冲突 | 末尾行为可配置（停留/提示/循环），不强制弹窗 |
| 7 | `custom_sort` 是空壳 | 设置中提供 4 种排序策略下拉 |
| 8 | 仅支持 jpg/jpeg/png | 默认 jpg/jpeg/png/bmp/webp/tiff，由设置控制 |
| 9 | 自动播放间隔写死 100ms | 设置中可调（滑块 50–2000ms） |
| 10 | closeEvent 中 quit() + super 重复 | 仅 super().closeEvent() |
| 11 | 撤销弹提示框对高频用户是干扰 | 默认改用 toast，可在设置中改回模态对话框 |
| 12 | 无已分类视觉提示 | 双层方案：内存层在右侧类别列表显示每类已分计数；持久层为每个源文件夹维护分类记录 JSON，重开后已分类的图带标记角标 |
| 13 | bidict 使用浪费 | 普通 dict，移除依赖 |
| 14 | 无进度条 | 状态栏显示 `N / Total` + 已分类总数 |
| 15 | `save_image` 功能定位模糊 | 删除该功能（与分类重复） |

## 10. 主动决策与待确认项

### 已决定

- ✅ **应用名称**：Magpie
- ✅ **配置存储**：`QStandardPaths.AppDataLocation` 下 JSON 文件（`preferences.json` + `state.json` + `classifications/<hash>.json`）
- ✅ **图像加载库**：Pillow（取代 OpenCV + numpy）
- ✅ **图像视图**：QGraphicsView
- ✅ **打包工具**：PyInstaller
- ✅ **图片来源 + 输出目录**：均可在设置 → 文件夹中预设默认值
- ✅ **同名冲突策略**：弹对话框（跳过/覆盖/重命名/取消），带"对本次会话记住此选择"复选框
- ✅ **类别快捷键**：仅支持单键（单个可见字符），UI 阻止其他输入
- ✅ **打开新文件夹时**：撤销栈清空（不跨文件夹保留）
- ✅ **BBox 可视化**：保留（核心需求之一）
- ✅ **自动播放**：场景是"浏览挑选 + 快速分类"，分类键在播放时立即响应、节奏不被打断
- ✅ **已分类标记持久化**：源文件夹关闭后再打开仍能看到标记，通过 AppData 下的 sidecar JSON 实现，不污染源目录
- ✅ **不做缩略图 / 网格视图**：保持单图浏览的极简形态
- ✅ **子目录递归扫描**：作为可选项加入"打开图片文件夹"流程 —— 若所选目录包含子目录，弹一次询问"是否递归扫描子目录"（带"记住此选择"复选项，写入 preferences）。设置 → 文件夹也提供全局默认开关
- ✅ **不做模型预标注辅助**：保持工具专注于"人工浏览 + 手动分类"，不引入模型推理依赖
- ✅ **不做多标签**（一图多类别在一次分类操作中）
- ✅ **v1.0 不做代码签名**
- ✅ **删除 v1 的"保存当前图像"菜单项**
- ✅ **图标**：黑白喜鹊侧面剪影 + 青蓝色尾羽点缀（见交付物 `magpie_icon.svg`）。提供圆角方形背景版（用于 macOS dock / Windows 任务栏）和纯透明背景版（用于文档/网站）
